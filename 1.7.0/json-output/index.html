    JSON Output

    odctl list, odctl explain, odctl ps and odctl info print one JSON document with --json, for scripts and AI assistants. The list, explain, ps and info tools of the MCP server return the same documents. This page holds the JSON Schema of each document, captured when the site was built. A JSON Schema lists the keys of a document, the type of each value and which keys are always present. Standard output holds only the JSON document. Warnings and errors go to standard error. A usage error, such as an unknown option, exits with code 2. Any other failure exits with code 1 and prints nothing on standard output. What Stays Stable in 1.x says which changes to these keys wait for 2.0.
