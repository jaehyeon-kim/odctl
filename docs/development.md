# Development

Pull requests are welcome. To work on the CLI:

1. Clone the repository and install [uv](https://docs.astral.sh/uv/).
2. Install the dependencies and the project in development mode:
   ```bash
   uv sync
   ```
3. Install the pre-commit hooks, which run the formatting and type checks:
   ```bash
   uvx pre-commit install
   ```
4. Run the tests:
   ```bash
   uv run pytest tests/
   ```
5. Build this site, then serve it locally while you edit:
   ```bash
   uv run mkdocs build --strict
   uv run mkdocs serve
   ```

The profile pages and the CLI reference are generated by `scripts/gen_pages.py` during the build, so edit `registry.yml`, the compose files or the commands rather than those pages.
