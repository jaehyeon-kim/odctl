# Open Data Stack (odctl)

**Run an open data stack on your machine, with its services already connected, from one command.**

odctl is a command-line tool that runs an open data stack on your machine with Docker Compose. You name the [profiles](how-it-works.md#profiles) you want, such as `kafka-lite` or `airflow`, and odctl starts them together with the services they depend on.

![odctl architecture](assets/diagram.png)

A Compose file of your own is enough for one small project. [Why odctl](about/why-odctl.md) explains what odctl adds when several projects need different parts of the stack.

## Commands

Each command has its own section in the CLI reference, with its options and examples. The Example column links to a page that runs the command and shows its output, and [Getting Started](getting-started.md) runs them in order on one profile.

| Command | Use it to | Example |
| --- | --- | --- |
| [`odctl list`](cli.md#odctl-list) | See every profile and what it runs | [Getting Started](getting-started.md#start-a-profile) |
| [`odctl explain`](cli.md#odctl-explain) | See a profile's services, images, ports and the profiles it depends on | [Getting Started](getting-started.md#start-a-profile) |
| [`odctl ps`](cli.md#odctl-ps) | See the running containers, their health and their ports | [Getting Started](getting-started.md#see-what-is-running) |
| [`odctl info`](cli.md#odctl-info) | Check the installed odctl version and whether Docker is reachable | [Getting Started](getting-started.md#see-what-is-running) |
| [`odctl init`](cli.md#odctl-init) | Copy the compose files and settings into `.odctl`, so you can edit them | [Getting Started](getting-started.md#create-a-workspace) |
| [`odctl pull`](cli.md#odctl-pull) | Download a profile's images before you start it | [How It Works](how-it-works.md#which-images-run) |
| [`odctl up`](cli.md#odctl-up) | Start profiles and the profiles they depend on | [Getting Started](getting-started.md#start-a-profile) |
| [`odctl down`](cli.md#odctl-down) | Stop profiles and remove their containers | [Getting Started](getting-started.md#stop-a-profile) |
| [`odctl logs`](cli.md#odctl-logs) | Read the logs of a profile's containers | [Getting Started](getting-started.md#see-what-is-running) |
| [`odctl restart`](cli.md#odctl-restart) | Restart a profile's containers and keep them | [Getting Started](getting-started.md#restart-a-profile) |
| [`odctl recreate`](cli.md#odctl-recreate) | Replace a profile's containers, to apply an edit to a compose file or `.env` | [How It Works](how-it-works.md#examples) |
